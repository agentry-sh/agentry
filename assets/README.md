# Repository media

Public, source-controlled assets for the Agentry GitHub homepage and workflow
documentation. Source files are retained beside reduced-motion PNG renders so
changes can be reviewed in pull requests. The original private-site generation
tooling is intentionally not part of the public repository.

## Homepage policy

The repository homepage uses native Markdown, text diagrams, lists, and tables.
Keep diagrams, reduced-motion demo posters, and workflow posters for focused
documentation and release notes. Add one to the homepage
only when it explains something the surrounding Markdown cannot express clearly.

GitHub’s repository social preview should use `social/repository-preview.png`.

## Formats

- `.png`: reduced-motion poster, link preview, and workflow card;
- `.svg`: editable, crisp architecture source.

Brand files in `assets/brand/` are canonical for the public project.
