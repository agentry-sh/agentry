# Support

## Community and source support

Use [GitHub Issues](https://github.com/agentry-sh/agentry/issues) for reproducible
bugs, documentation problems, workflow proposals, and focused feature
requests. Search existing issues first and include the affected commit,
component, expected behavior, and a minimal reproduction with all customer data
and credentials removed.

GitHub Issues are public and are not an account-support or emergency channel.
Maintainers do not guarantee a response time for community support.

## Hosted-service support

For billing, account access, data deletion, or a problem involving private
hosted-service details, email `support [at] agentry.sh`. Include a project ID
only when needed; never send API keys, OAuth codes, invite tokens, telemetry
payloads, or onboarding proof markers.

Report suspected vulnerabilities privately as described in
[SECURITY.md](./SECURITY.md), not through a public issue.
